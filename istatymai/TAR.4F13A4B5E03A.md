# Lietuvos Respublikos dimisijos karių laipsnių suteikimo ginkluoto pasipriešinimo (rezistencijos) dalyviams-kariams savanoriams ir prieškario Lietuvos kariuomenės kariams įstatymo 2 straipsnio pakeitimo įstatymas

LIETUVOS RESPUBLIKOS
DIMISIJOS KARIŲ LAIPSNIŲ SUTEIKIMO GINKLUOTO PASIPRIEŠINIMO (REZISTENCIJOS) DALYVIAMS-KARIAMS SAVANORIAMS IR PRIEŠKARIO LIETUVOS KARIUOMENĖS KARIAMS ĮSTATYMO 2 STRAIPSNIO PAKEITIMO
ĮSTATYMAS
2012 m. birželio 29 d. Nr. XI-2185
Vilnius
(Žin., 1998, Nr. [38-997](https://www.e-tar.lt/portal/lt/legalAct/TAR.18EEE2BC90F6))

#### 1 straipsnis. 2 straipsnio 2 dalies pakeitimas
Pakeisti 2 straipsnio 2 dalį ir ją išdėstyti taip:
„2. Karių savanorių laisvės kovotojų struktūrose eitos pareigos prilyginamos šiems Lietuvos Respublikos sausumos ir karinių oro pajėgų dimisijos karių laipsniams:

| Laisvės kovotojų struktūrose | Sausumos ir karinių oro |
| --- | --- |
| nustatytos pareigos | pajėgų karių laipsniai |

| partizanas | eilinis |
| --- | --- |
| grandininkas | grandinis |
| skyrininkas, grupės vadas | seržantas |
| būrio vado pavaduotojas, būrininkas, skyriaus vadas | vyresnysis seržantas |
| būrio vadas | viršila |
| kuopos vado pavaduotojas, kuopos vadas, rinktinės adjutantas | leitenantas |
| rinktinės štabo skyriaus viršininkas, tėvūnijos štabo viršininkas | vyresnysis leitenantas |
| tėvūnijos vadas, atskirojo būrio vadas, apygardos adjutantas, rinktinės vado pavaduotojas, rinktinės štabo viršininkas | kapitonas |
| apygardos štabo skyriaus viršininkas, apygardos gydytojas, apygardos kapelionas, rinktinės vadas | majoras |
| apygardos vado pavaduotojas, apygardos štabo viršininkas, srities štabo viršininkas, politinės dalies viršininkas | pulkininkas leitenantas |
| apygardos vadas, srities vadas | pulkininkas |
| gynybos pajėgų vadas | brigados generolas. |
